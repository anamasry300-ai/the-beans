# The Beans

Specialty coffee store. From Port Said to the World.

Static site (HTML/CSS/JS). Deployable to GitHub Pages.

## Run locally
Open index.html in a browser, or serve with npx serve.

## Structure
- index.html home
- shop.html products + filters
- product.html?id=...
- about.html brand philosophy
- brewing.html brew methods
- origins.html explore by origin
- admin.html (interface only, no backend)
